# Skill 名称

**Wakinyeol's photo-outfit-color-cards（穿搭照片圆形色卡）**

## 适用场景

- 用户提供穿搭照片，希望识别衣服、裤子、鞋、帽子、围巾、手套、包等的代表色，并生成圆形色卡。
- 用户希望沿用参考图的视觉风格：圆形纯色色块、透明背景、柔和投影。
- 照片有多个人，需要分别取色、分别成组，最后在原图空白处排版。
- 用户要先看独立色卡预览，调整颜色、数量或顺序，确认后才加到照片上。

不用于不涉及照片的品牌色规范、印刷级色彩校准，或要求精确保留复杂花纹/渐变的场景。

## 输入信息

执行前确认或从上下文获取：

1. **原始照片**：可读取的文件；多人时能区分左/右或人物身份。
2. **参考样式**（可选）：如参考图、圆圈大小、阴影强度、排列方向。
3. **取色范围**：哪些服饰和配件需要包含；用户明确要求忽略的部位不得加入。
4. **颜色偏好**：如“裤装用正白色”“帽子白色更冷一点”。这种指定色优先于像素取样。
5. **合成位置**：若未指定，从画面中找空白处；若已指定，优先遵循，并检查是否遮挡人物。
6. **交付路径**：保存预览 PNG 和最终合成 PNG 的可写目录；保留原始照片不覆盖。

缺少非关键偏好时，先给出合理的代表色方案，不因色卡数量、位置等小问题阻断预览。若用户要求“先确认”，**确认前只生成独立预览，不制作或交付已叠加版本**。

## 执行步骤

1. **看图与分组**：辨认每个人的穿搭部位和可用空白区域；多人按人物分别列清单。背景、头发及手机等不自动算作穿搭色。
2. **取代表色**：从各物件的主体区域采样，避开高光、褶皱阴影、边缘和被其他物品遮挡的区域。近似颜色可合并；花纹只保留能代表搭配的底色或醒目色，不机械提取所有颜色。说明照片光线会影响数值；若用户指定视觉色，以指定值为准，不称其为原图精确取样。
3. **独立预览**：每个人单独生成一张透明 RGBA PNG；用纯色圆圈、轻微投影，保持尺寸、间距和顺序一致。先验证透明区域确实为透明，避免预览器的黑色底被误当作图片背景。
4. **提交确认**：展示每组预览，并列出“所属人物—部位—HEX/RGB”。明确说“尚未加入原图”，询问是否需要调整。没有可辩护的面积估算时，不编造颜色占比。
5. **按反馈修改**：删色、调色、改顺序或调整两组数量时，只改相应组并重新展示；保留用户已认可的其他决定。再次等待明确确认。
6. **合成到原图**：始终从**原始照片**重新合成，不在旧成品上叠加，防止残留旧色卡。根据真实像素尺寸定位，不凭聊天窗口缩略图直接使用坐标。可横排或竖排，不遮挡脸、手、帽子、服装关键细节；多人各组要易于对应人物。色块的阴影独立绘制，保持轻柔；尽量保留原图分辨率。
7. **目视验收与交付**：检查最终图片是否出现裁切、重叠、间距不齐、错误颜色或旧版色卡残留；检查白色色块在浅背景上仍可辨识。提供最终 PNG 预览与文件链接，说明原图未被改动。

## 核心 Prompt

供未来类似任务直接使用；将方括号替换成实际信息：

> 请分析我提供的穿搭照片，为[每个人/指定人物]分别提取[服饰及配件范围]的代表色。参考[参考图或描述]，生成**透明背景、圆形纯色色块、柔和阴影**的独立色卡预览。每个颜色注明人物、来源部位和 HEX/RGB；优先遵守我指定的颜色及排除项。请先展示预览让我确认，**未确认前不要加到原图上**。如我提出删减、调色或改变排列，请只调整相应内容并再次确认。确认后，从原始照片重新合成，将各组色卡放在[指定位置或合适空白处]，避免遮挡人物，最后展示合成图并提供 PNG。

## 判断标准

- **取色**：每个色块能对应清晰的服饰/配件；用户指定的色值和排除项已落实；多人没有串色。
- **预览**：真正透明的背景、规则的圆形、柔和而不过重的阴影；同组布局整齐。
- **确认流程**：预览与合成分两阶段；用户确认之前未将色卡加进原图。
- **成品**：尺寸与原图一致或符合用户要求；色卡数量、顺序、位置正确，不盖住主体，不出界、不重叠；原图未被覆盖。
- **沟通**：清晰区分“照片采样近似色”和“按用户审美指定的颜色”；交付可打开的 PNG。

## 常见问题

- **看图缩放比例与文件尺寸不同**：聊天预览可能缩小，实际绘制坐标要按原图像素换算并目视检查。
- **一处采样过暗或偏色**：衣物褶皱、室内暖光、镜面反射会影响像素；选主体区域的多点代表值，再做视觉核对。
- **色卡预览显示黑底**：透明 PNG 在某些预览器中会显示黑色画布；检查 Alpha 通道，不要误把黑底烘焙进文件。
- **白色色块不明显**：用适量投影增加边界感，而非擅自把用户要求的白色改成灰色。
- **重新布局产生旧色卡残留**：每次从未编辑的原始照片出图；不要以此前的合成 PNG 为底图。
- **花纹色过多**：优先表达搭配中最重要的颜色；不要因为包或围巾有花纹，就无条件加上所有深色纹样。
- **多人色卡归属不清**：分别预览并标注人物；最终位置可按左右、上下对应，必要时调整而不是强求某一种布局。

## 优化建议

- 将“取样区域、用户指定颜色、最终 HEX、人物/部位标签”保存为结构化清单，修改时避免误改另一组。
- 将圆圈直径、间距、阴影模糊、排列方向及锚点设为可配置参数，便于针对不同纵横比复用。
- 加入自动检查：透明预览的 Alpha、同组色块数量、边界是否超出画布，以及与人像主体区域是否相交；最终仍要人工目视确认。
- 如果用户需要精确配色，提供更严格的多点采样、色彩空间与光照说明；普通穿搭配色继续以视觉协调为优先。
